# Rinemi — Public Beta Checklist

## Before inviting users

- public positioning is understandable without project history
- first-open onboarding is understandable
- guest learning works before account creation
- account benefits are explicit
- backup/restore is understandable
- offline core loop works
- major target browsers have been exercised
- errors are actionable
- help/support paths are visible
- privacy/terms text matches production behavior

## During beta

Record structured observations for:
- onboarding completion/confusion
- first-session completion
- repeat return behavior
- sync failures and conflicts
- offline failures
- backup/restore failures
- content reports
- accessibility problems
- browser/device-specific defects
- performance regressions

## Exit gate

Do not promote beyond beta until all R19 release-gate conditions are evidenced.

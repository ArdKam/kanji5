# Kanji5 — Feedback & Support

For bugs, UX problems, accessibility issues, or feature requests, use the repository's public issue tracker:

https://github.com/ArdKam/kanji5/issues/new/choose

Please include:
- browser and OS/device
- what you expected
- what happened
- whether the problem was online/offline
- a short reproduction path

Do not include passwords, auth tokens, private backup files, or unnecessary learner history in public issues.

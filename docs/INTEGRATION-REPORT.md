## Status vocabulary

- **Implemented:** the code/doc diff exists on a branch or main.
- **Tested:** the specified checks completed successfully for that exact SHA.
- **Merged:** the change is on current `main`.
- **Deployed:** a deployment succeeded for that exact main SHA.
- **Production-verified:** live artifact/configuration or behavior was checked after that deployment.

These states are independent; one does not imply the next.

# Code of Conduct

Rinemi is intended to be a respectful technical and educational project.

## Expected behavior

- Be respectful and constructive.
- Critique ideas and code without harassing people.
- Do not post personal information, credentials, private backups, or private learner data.
- Do not use public issues to disclose security vulnerabilities.
- Respect third-party licenses, attribution, and contribution boundaries.

## Unacceptable behavior

Harassment, threats, discrimination, doxxing, deliberate abuse of project infrastructure, or malicious disclosure of private/security-sensitive information are not acceptable.

## Enforcement

Maintainers may remove content, close discussions, or restrict participation when necessary to protect contributors, users, or the project. Security reports must use the private channel described in SECURITY.md. Privacy/account requests currently have no dedicated private channel.
